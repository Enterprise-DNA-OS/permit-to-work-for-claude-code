---
description: The monthly permit audit: every rule finding, permits closed in the last 30 days with their handback, fire watch times, and where the isolation hours went.
---

Run `npm run permits -- compliance`, `npm run permits -- permits` and `npm run permits -- history`, and `npm run view -- history`. Report: findings by rule with a count, permits closed without a proper handback or fire watch, the three assets with the most isolation hours and what that says about maintenance. Save it with `/draft-weekly` if the operator wants it kept.
