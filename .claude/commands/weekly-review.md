description: The Monday safety review, written from attention, the rule findings, tickets to renew and isolation hours.
---

Run `npm run permits -- attention`, `npm run permits -- expiring` and `npm run permits -- history`. Write five lines: the breaches to fix this week, the permits that ran long or clashed, the tickets and certificates to renew, the asset that keeps getting isolated, and one change to the site procedure worth making. Then run /draft-weekly to save it.
