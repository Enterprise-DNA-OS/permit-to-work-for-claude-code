---
description: The start-of-shift check for the permit coordinator: who is inside, what is live, what breaks a rule, what is waiting to be issued and what ends this shift.
---

Run `npm run permits -- attention`, then `npm run permits -- inside` and `npm run permits -- board`. Lead with anyone inside a confined space and their standby. Then every breach, with the next action and the command that does it. Then permits ending soon and permits waiting to be issued with what each still needs. Five lines at most before the tables. Nothing changes until the operator says yes.
