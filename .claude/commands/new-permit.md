description: Request a permit: kind, area, equipment, task, receiver and times. It starts as requested and is issued with /issue once its controls are in place.
---

Ask for anything missing, then run `npm run permits -- request --kind=<kind> --area=<area> --asset=<asset> --task="<task>" --receiver=<person> --from="<YYYY-MM-DD HH:MM | now | +1h>" --hours=<n> --risk=<JSA ref>`. Kinds: `npm run permits -- kinds`. Report the permit code and the next steps it prints.
