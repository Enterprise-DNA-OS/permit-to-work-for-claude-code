---
description: Record a gas test on a permit. The tester must hold a current gas testing ticket. The result says which reading failed, if any.
---

Run `npm run permits -- gas-test <permit> --by=<tester> --o2=<%> --lel=<% LEL> --h2s=<ppm> --co=<ppm> --location="<where>"`. Add `--no-bump` if the monitor was not bump tested. If it fails, the next step is everyone out, ventilate, retest.
