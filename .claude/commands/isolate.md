---
description: Isolate an asset: lock out its energy points with lock numbers, by an authorised isolator, optionally linked to a permit. Names any point still live.
---

Show the asset's points first (`npm run permits -- asset <asset>`). Then run `npm run permits -- isolate <asset> --by=<isolator> --points=<POINT:LOCK,...> --lockbox=<box> --permit=<permit>`. Then /verify once zero energy is proved.
